# Accessibility Notes

This activity was designed with WCAG 2.2 AA practices in mind.

## Included features

- semantic headings and page landmarks
- keyboard-operable controls
- visible focus indicators
- large target sizes
- no drag-and-drop requirement
- no timed interaction
- no autoplaying media
- choice-specific text feedback
- ARIA live announcements
- focus movement to each new screen heading
- reduced-motion support
- high-contrast text and controls
- responsive layout
- descriptive iframe title in the Canvas example
- plain-language instructions

## Important limitations

- Accessibility should still be tested in the institution's actual Canvas theme and supported browsers.
- Canvas or institutional iframe settings can affect the experience.
- This activity does not report completion or grades to Canvas.
- The reflection field is not submitted or saved.
