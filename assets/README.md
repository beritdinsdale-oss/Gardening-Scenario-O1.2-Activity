## Easiest way to replace a photograph

Replace the existing image with a new image that has **exactly the same filename**.

For example, to replace the hydrangea photograph:

1. Rename your new photograph `scenario-4-hydrangea.jpg`.
2. Upload it into this `assets` folder.
3. Confirm that GitHub asks to replace the existing file.
4. Update the alt text and photo credit in `content.json`.

Keeping the filename unchanged means you do not need to change the image path in `content.json`.

Use JPG images when possible. Landscape-oriented images approximately 1200 pixels wide work well.
